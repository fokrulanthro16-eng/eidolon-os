## Near-term (Phase 21–25)

### Phase 21 — Tauri Desktop Shell
- System tray icon + quick-capture hot key
- Native OS notifications for memory events
- Single-EXE installer (~8 MB, no Chromium)
- Auto-start with Windows

### Phase 22 — Memory Timeline UI 2.0
- Infinite scroll timeline with visual clusters
- Day/hour heat-map navigation
- Cross-modality merge view (screenshot + voice + PDF in one row)
- Drag-to-annotate

### Phase 23 — Smart Recall (Contextual)
- Automatic context injection: what was I working on at this time?
- Periodic idle nudges: "You haven't captured anything in 2h"
- Daily digest exported as Markdown

### Phase 24 — Mobile Companion (React Native)
- View memories from mobile
- Quick voice note → memory
- Push: "Memory captured" notification from desktop

### Phase 25 — Local Knowledge Graph UI
- Visual node-edge graph for memory relationships
- Filter by topic / app / time range
- Export graph as GraphML / JSON

---

## Long-term (Phase 26+)

- **Multi-device sync** — local LAN sync (no cloud), encrypted
- **Plugin system** — third-party memory sources (GitHub, Notion, Obsidian)
- **LLM fine-tuning** — personal model trained on your own memories
- **Voice assistant** — always-on local wake word ("Hey Eidolon")
- **EIDOLON Cloud** — opt-in encrypted backup (Phase 30+, user-controlled)

---

## Non-goals (will never be built)

- Surveillance or tracking of other people
- Cloud data storage without explicit opt-in
- Required API keys or subscriptions for core functionality
- Selling user data in any form
